# 表格结构化提示词

> 用途：把 `tools/table_extract_tool.py` 解析出的表格单元格，整理成结构化字段。
> 该提示词仅在需要"理解表头语义"时使用；纯结构解析不需要模型。

---

下面是一张从公告 PDF 中解析出的表格，已包含每个单元格的文本。

请完成两件事：

1. **识别表头**：给出表头行的行号（从 0 开始）。如果该表格没有表头，输出 `null`。
2. **逐行给出字段**：对每一数据行，输出一个对象，键为表头文本，值为该行对应单元格的原文。

## 约束

- **只使用给定单元格的文本**，不得推理、不得计算、不得改写
- 空单元格输出空字符串 `""`，**不要填 0，不要用相邻单元格补全**
- 如果无法确定表头，`header_row` 输出 `null`，并仍然逐行输出 `row_index` 与 `cells` 原文
- 如果表格结构异常（行列数不一致、存在合并单元格），在 `issues` 中如实说明，不要强行对齐

## 输出格式

```json
{
  "header_row": 0,
  "columns": ["项目名称", "中标金额", "中标日期"],
  "rows": [
    {"row_index": 1, "cells": {"项目名称": "...", "中标金额": "...", "中标日期": "..."}}
  ],
  "issues": []
}
```

## 示例

输入单元格矩阵：

```
[["项目名称", "中标金额", "中标日期"],
 ["青岚智慧园区配套工程", "人民币1,280.50万元", "2026年10月10日"],
 ["河畔智慧园区配套工程", "尚未确定", "2026年10月12日"]]
```

应输出：

```json
{
  "header_row": 0,
  "columns": ["项目名称", "中标金额", "中标日期"],
  "rows": [
    {"row_index": 1, "cells": {"项目名称": "青岚智慧园区配套工程", "中标金额": "人民币1,280.50万元", "中标日期": "2026年10月10日"}},
    {"row_index": 2, "cells": {"项目名称": "河畔智慧园区配套工程", "中标金额": "尚未确定", "中标日期": "2026年10月12日"}}
  ],
  "issues": []
}
```

注意第二行的 `中标金额` 是"尚未确定" —— 按原文照抄，**不要变成 null 也不要变成 0**（是否为缺失由后续规则判断）。
