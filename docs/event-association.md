# 事件字段归属检查

逐字引文和坐标只证明文字存在，不证明其属于当前项目。新增检查在原有证据定位后运行：同页多个项目以项目锚点所在句的起点划分候选范围，金额、公司、招标方、中标日期的证据必须位于该范围且唯一。公告日期和币种可以共享。

锚点同句、重复锚点、同范围重复字段或金额标签多于提取事件时，保守转为待复核。association_status=no_conflict_detected 仅表示未发现这类冲突，不能理解为语义正确性证明。原始字段和证据不被篡改。

范围限制：句子划分不能替代表格行列解析，也不解决跨页、联合体和省略项目名称的复杂关联。这些仍需人工核验。多金额合法公告可能因此被保守提示，需在真实数据上衡量误报。未来应以保留的标题、项目编号和表格结构替代句子启发式。
