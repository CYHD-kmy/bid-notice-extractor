# 人工复核与留痕

在页面选择事件和字段，填写复核人，再选择确认原值、提出修改或仍需复核。修改与保留疑点必须说明理由。日志包含运行编号、输入指纹、事件编号、原值、建议值、原证据和时间。

日志只保存在当前浏览器的 localStorage，按运行和输入指纹隔离。请点击“导出结果及复核日志”下载备份并交给团队；更换浏览器或清除网站数据会失去本地记录。本次没有服务端多用户协作或身份认证，复核人是自行填写的署名，不属于可认证的签名。

导出文件保留 automatic_result 和独立 review_log。建议修改值不自动替换模型结果、不继承旧证据、不重新计算标准金额，也不提高自动评测成绩。团队应在核验新证据和计算后另行接纳修改。该设计避免把人为修正包装为模型正确率。
