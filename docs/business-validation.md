# 金额口径与异常状态

保留金额原文，使用 Decimal 换算。新增成交金额标签、含税或不含税标记以及缺失原因。没有提取到金额不等同于原文未披露：not_extracted、not_disclosed、not_applicable 分别记录。

合同金额、预算、最高限价、联合体总额和合计不能直接作为单项目中标金额。模型可提供原文中的 award_amount_type 标签；标签不属于明确中标或成交口径时清空标准金额并提示复核。标签缺失时保留兼容行为，不能据此声称口径已证明。是否为某成员可确认的份额仍需事件证据检查。

原始字段不被覆盖。新增 normalized 子字段是兼容扩展，已有 JSON/CSV 核心字段仍可使用。未解决大写金额、外币汇率换算和复杂联合体份额计算。
